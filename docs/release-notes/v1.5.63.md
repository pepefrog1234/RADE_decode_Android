# v1.5.63 — コールサイン表示の維持＋ネットワーク接続での Bluetooth マイク修正

2 件のご報告、どちらもアプリのバグでした。修正しましたのでご確認ください。インストールは `app-debug.apk` をご利用ください。

## ① RX Call のコールサインが早々に消える件

**原因**：送受信の切り替えのたびに内部のオーディオエンジンが作り直され、その「空のコールサイン」で画面表示が毎秒上書きされていました。また送信終了時の状態リセットでも消えていました。

**修正**：表示は**新しいコールサインが解読されるまで維持**されるようになりました（freedv-gui と同じ挙動です）。他局の信号を受信し始めても、その局の EOO（オーバー終了時のコールサイン送出）が解読された時点で初めて表示が入れ替わります。

## ② A2DP Bluetooth ヘッドセットのマイクが認識されない件

まず前提として：**A2DP プロファイル自体にはマイクがありません**。Bluetooth ヘッドセットのマイクは通話用の SCO（または LE Audio）経路で動作し、本アプリでは設定の「**Bluetooth マイク（送信）**」スイッチがその経路を有効にします（送信マイクの機種選択リストではありません）。

その上で本題のバグ：このスイッチが **ネットワーク接続（HL2 (LAN)・Thetis (VBAN)・Wi-Fi (IC-705)）では無効になっており**、オンにしても常に内蔵マイクが使われていました。USB 接続の無線機でのみ動作する実装だったためです。

**修正**：ネットワーク送信でも USB 接続時と同じ Bluetooth マイク処理が働くようにしました — LE Audio（LC3）優先・クラシック SCO フォールバック・切替遅延対策（リンク先行ネゴシエーション）・ノイズ抑制／AGC の無効化まで同一です。

**音質のご注意**：クラシック Bluetooth の SCO は電話品質（こもった音）になります。これはコーデックの仕様で、アプリ側では改善できません。音質を重視される場合は有線イヤホンマイクまたは USB マイクをおすすめします（設定 → 送信マイクで選択、v1.5.61 でネットワーク接続にも対応済み）。

## 確認方法

1. v1.5.63 に更新
2. **コールサイン**：複数局が交互に送信する状況で、表示が次の局の EOO 解読まで維持されることをご確認ください
3. **Bluetooth マイク**：「Bluetooth マイク（送信）」を ON → HL2 (LAN) または Thetis (VBAN) で送信 → ヘッドセットのマイクで変調されることをご確認ください

## English summary

Two app bugs fixed:

1. **RX-Call display cleared too early.** Every TX→RX cycle rebuilds the
   audio engine, whose empty callsign string was overwriting the display
   each second (and the TX-teardown state reset wiped it too). The
   decoded callsign now **persists until a new station's EOO decodes**,
   matching freedv-gui behavior.
2. **Bluetooth-mic toggle ignored in network modes.** The experimental
   "Bluetooth mic (TX)" switch only worked with USB-connected rigs; in
   HL2 (LAN), Thetis (VBAN) and Wi-Fi (IC-705) modes it silently fell
   back to the built-in mic. Network TX now runs the same LE Audio
   (LC3)-first / classic-SCO-fallback routing as the USB path (native
   startNetTx gained a voice-communication capture flag for LC3).
   Reminder: A2DP itself has no microphone — a classic BT headset mic is
   telephony-grade SCO; use a wired/USB mic for full quality.
