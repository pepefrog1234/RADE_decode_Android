# v1.6.5 — Report the real app version to FreeDV Reporter

Small fix: the version string sent to qso.freedv.org was hardcoded as `RADE_Android/1.0`, so every station running this app showed up as "1.0" on the FreeDV Reporter site and in the in-app Stations list, regardless of the installed build.

From this release the app reports its actual version automatically (e.g. `RADE_Android/1.6.5`), and future releases will keep it in sync without manual updates.

No audio, rig-control, or decoding changes. Install `app-debug.apk`.
