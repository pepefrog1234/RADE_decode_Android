# v1.6.9 — Icom Wi-Fi：トークンを保存し、次回接続時に自動削除 / Persist & auto-remove the token

Icom Wi-Fi 再接続問題の最終修正版です。インストールは `app-debug.apk` をご利用ください。

## 修正内容（日本語）

v1.6.8 は「切断ボタンでの正常な切断」のトークン削除を確実化しましたが、**アプリの強制終了・クラッシュ・電波状況によるパケットロス**などでトークンが無線機に残った場合は、依然として次のログインがブロックされていました（アプリ更新直後の初回接続の失敗もこれが原因です）。

v1.6.9 では、ログイン成功時に**トークンをスマホ側に保存**し、**毎回の接続の最初に前回のトークンの削除指令を自動送信**するようにしました。削除は冪等（すでに消えたトークンを消しても無害）なので無条件に実行されます。これにより、**前回のセッションがどんな終わり方をしても**、次の接続は自動的にクリーンな状態から始まります。

## お試し手順

1. v1.6.9 に更新する
2. **今回だけ** IC-705 の電源を一度入れ直してください（旧バージョンはトークンを保存していないため、残っている場合の最後のクリーニングです）
3. 以降、電源の入れ直しは**不要**です。以下がすべて毎回つながることをご確認ください：
   - 接続 → 切断ボタン → 再接続 の繰り返し
   - 接続中にアプリを強制終了（タスクキル）→ アプリを起動して再接続

NG が出た場合は、何回目・エラー文言・前回の終わり方をお知らせください。

## In English

Final fix for Icom Wi-Fi reconnects. v1.6.8 covered clean disconnects; a token left on the radio by an unclean exit (app killed/crashed while connected, or removal packets lost) still blocked the next login. v1.6.9 persists the token on the phone the moment login succeeds, and every connect begins by sending a removal for the previous token (idempotent, sent unconditionally). No radio power-cycle or waiting is needed anymore, regardless of how the previous session ended — except once right after updating from an older version, to clear any token those versions could not save.
