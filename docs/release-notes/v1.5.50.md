# v1.5.50 — RX→TX 切替の約7秒の遅延を修正（LC3 イヤホン接続時）

ご報告いただいた「送信への切替に約7秒かかる」問題の修正版です。インストールは `app-debug.apk` をご利用ください。

## 原因と修正内容

LC3 イヤホンが接続されている状態でスマホ内蔵マイク（または USB マイク）を開くと、Android がそのマイクをイヤホンの LC3 グループに割り込ませようとして、失敗する再構成処理が走ります。**送信開始のたびに、この失敗処理が終わるまでマイクのオープンが数秒間ブロックされていた**のが、約7秒の遅延の正体です（v1.5.46 のログに記録されていた現象と同じ機構です）。

v1.5.48 では受信側のキャプチャにのみ同じ対策を入れていましたが、今回**送信側のマイクにも適用**しました。LC3 イヤホン接続中に内蔵/USB マイクで送信する場合、イヤホンの LC3 グループに干渉しないキャプチャ方式（VOICE_RECOGNITION）でマイクを開きます。

※ TX→RX の約3秒は、コールサイン（EOO フレーム）を最後まで電波に乗せてから PTT を落とすための意図的な待ち時間で、変更していません。

## お試しいただきたいこと

1. v1.5.50 に更新（設定は普段どおり：内蔵マイク＋LC3 イヤホンで受信）
2. RX→TX の切替時間が短くなったかご確認ください
3. TX→RX を数回繰り返しても、イヤホンの音が途切れないかご確認ください

## Bluetooth マイク（通話モード）が動作しない件について

こちらはまだ調査中です。原因の特定にログが必要ですので、お手数ですが以下のご協力をお願いします：

1. 「**送信に Bluetooth マイクを使う**」を **ON** にした状態で、受信開始 → TX を1回 → RX に戻す、まで再現する
2. その直後に、設定 → 診断 →「**Capture audio log (LC3/BT)**」でログを取得し、コピーして Issue に貼り付ける
3. あわせて、**スマホの機種名・Android バージョン・イヤホンの型番**もお知らせください
