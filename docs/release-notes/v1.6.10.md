# v1.6.10 — Show up on FreeDV Reporter without a grid square + manual frequency entry

Fixes two related reports: "my callsign never appears on FreeDV Reporter" and "the frequency on the Rig tab can't be set".

## Why the callsign never appeared

qso.freedv.org **refuses the whole connection** when the auth packet has an empty `grid_square`, or when the callsign contains a character its validator rejects (a space, or a full-width letter from a Japanese IME). The app sent the Grid Square field verbatim — empty on a fresh install / after a data reset — so the server dropped the session right after the handshake, silently: the Stations tab just showed "Not connected" with no reason, no retry, and the station never appeared on the site.

- **Empty grid** → the app now reports `UN00KN` ("unknown locator", the same placeholder ezDV uses) instead of being refused. Entering a real grid square is still recommended so the distance/map features work.
- **Callsign / grid input sanitizing** → full-width characters are converted to ASCII, spaces are dropped (callsign: `A–Z 0–9 /`, grid: letters/digits). Saved values from older builds are sanitized on load too.
- **Refusals are now visible** → the server's refusal reason (Socket.IO `CONNECT_ERROR` / disconnect payload, previously ignored) is shown in the Stations tab hint, and the app keeps retrying with backoff instead of going idle forever. Server-initiated closes (restarts) also reconnect now.
- **GPS grid actually works** → `LocationTracker` was never started, so the GPS grid was always empty. It now starts when permission is available, and a **GPS** button next to the Grid Square field requests the permission.

## Frequency entry without a rig

The Rig tab frequency field was disabled unless CAT (rigctld / HL2 / VBAN) was connected — so with no rig connection the frequency could not be set at all, and FreeDV Reporter showed an empty Frequency column for the station.

The field is now always enabled, mirroring freedv-gui's frequency box:

- **Rig connected** → behaves as before (sets the rig VFO + auto data mode).
- **No rig** → Set stores the value as the manual dial frequency, shows it on the tab, persists it across restarts, and reports it to FreeDV Reporter (`freq_change`), so the band/frequency columns on qso.freedv.org are filled in.
- The current frequency (rig or manual) is also pushed right after every reporter (re)connect instead of only when RX/TX starts.
- `set_freq` rejections from rigctld (`RPRT -n`) no longer flash the rejected value on the display before snapping back.

Also: placeholder locators such as `UN00KN` are no longer plotted at bogus coordinates on the in-app map.

Install `app-debug.apk`.
