# v1.6.7 — Icom Wi-Fi：2回目以降の接続が失敗する問題を修正 / Fix reconnect failures

IC-705（Wi-Fi・子機モード）で「**インストール直後の1回目は接続できるが、2回目以降は『No login reply』でほぼ失敗する（たまに成功する）**」問題の修正版です。インストールは `app-debug.apk` をご利用ください。

## 原因（日本語）

切断時に Icom プロトコルの「切断パケット」を送っていなかったため、IC-705 側に前回のセッションが残り、その間の新しいログインが無視されていました。さらにアプリが毎回同一のセッションIDで接続していたため、残存セッションと同じ身分と見なされ、UDP のハンドシェイクには応答があるのにログインだけ無視される状態でした。新規インストール直後は残存セッションが無いため、1回目だけ成功していました。

## 修正内容

1. **切断時に切断パケットを送信**（3ストリームすべて）——IC-705 側のセッションが即座にクリアされます
2. **セッションIDを接続ごとにランダム化**——万一残存セッションがあっても別身分で接続できます
3. **ログインを最大3回・5秒間隔でリトライ**——セッション清掃中のタイミングでも接続が成立します

接続・切断を何度か繰り返して、毎回接続できることをご確認ください。

## In English

Fixes Icom network (IC-705 Wi-Fi) reconnects: the first connect after installing worked, but later connects usually failed with "No login reply". The app never sent the protocol's stream-level disconnect packet, so the radio kept the old session alive and silently ignored the next login — and the app presented the identical session ID on every connect, colliding with that stale record. v1.6.7 sends the disconnect packet on all three streams, randomizes the session ID per connect, and retries the login up to 3× at 5 s intervals.
