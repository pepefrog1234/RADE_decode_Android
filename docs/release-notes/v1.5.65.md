# v1.5.65 — PureSignal 第 2 段階（前半）：補正エンジンを搭載

第 1 段階のご確認（受信が従来どおり完璧とのこと）ありがとうございました。本バージョンでは、**Thetis と同じ PureSignal 本体（オープンソースの WDSP、Warren Pratt NR0V 氏作）をアプリ内に移植・搭載**しました。インストールは `app-debug.apk` をご利用ください。

## 本バージョンの内容

- WDSP の PureSignal 核心部（キャリブレーション計算 `calcc` と送信 I/Q 補正 `iqc`）を、原典のコードほぼそのまま（GPL ライセンス表記込み）アプリのネイティブライブラリに組み込みました
- Thetis の PS 画面が読んでいるのと同じ**状態ベクトル**（フィードバックレベル・キャリブレーション回数・補正動作中フラグ等）も取得できるようにしてあります — 第 3 段階の調整で使います
- **このバージョンではエンジンはまだ休止状態です**（どこからも呼ばれません）。動作リスクをゼロに保ったまま「部品を先に載せる」段階で、普段の運用に変化はありません

## 次の段階（第 2 段階・後半）

フィードバック信号の取り込み（fb1/fb2 のどちらに乗っているかの自動判定）、送信参照信号との時間合わせ、送信チェーンへの補正の組み込み、そして **PureSignal スイッチ（既定 OFF）**の追加です。その版から実際の ON/OFF テストをお願いすることになります。

もしお時間があれば、v1.5.64 のお願い（送信数秒 → 設定 → 診断 → Capture audio log で `fb1=`/`fb2=` の値）がまだでしたら、次の段階の設計に使いますのでいただけると助かります。

## English summary

**PureSignal Phase 2a: the correction engine is now on board.** The
WDSP PureSignal core (calcc calibration computer + iqc TX I/Q
corrector, by Warren Pratt NR0V — the same code Thetis uses) is
vendored nearly verbatim into the app's native library (GPL notice at
docs/licenses/WDSP-NOTICE.md), wrapped behind a small facade with JNI
bindings including the 16-int PS state vector Thetis's display reads.
The engine ships **dormant** — no callers yet, zero behavior change —
so this release carries no operational risk while the parts land.

Phase 2b next: feedback capture (auto-detecting which receiver carries
it from the fb1/fb2 diagnostics), TX-reference time alignment, wiring
feed/apply into the TX chain, and a PureSignal switch (default OFF).
