# v1.5.52 — LC3 通話モード中の音量キーを修正

動作確認のご報告ありがとうございました！ LC3 での送信・マイク・受信がすべて動作しているとのこと、とても嬉しいです。本バージョンは残っていた細かい2点への対応です。インストールは `app-debug.apk` をご利用ください。

## 音量調整が効かない件 → 修正しました

LC3 通話モード中の受信音声は「通話音量」で管理されるのですが、これまでアプリは音量キーを「メディア音量」に向けたままだったため、音量キーを押しても何も変わらないように見えていました。本バージョンから、**LC3 通話モードの動作中は音量キーが通話音量を調整**するようになります（停止すると通常のメディア音量に戻ります）。

なお、アプリ内の受信音量スライダーはどのモードでも常に有効ですので、そちらでも調整できます。

## イヤホン本体のノイズキャンセリングが効かない件 → イヤホン側の仕様です

LC3 の双方向（通話）状態に入ると、多くのイヤホンは**イヤホン自身のファームウェアが** ANC を無効化したり動作を変えたりします。これは Android アプリから制御できない層の動作のため、アプリ側での対応はできません。この挙動は設定画面の「送信に Bluetooth マイクを使う」の説明文にも追記しました（英・日・簡体字・繁体字）。

## お試しいただきたいこと

1. v1.5.52 に更新する
2. 「送信に Bluetooth マイクを使う」を ON にして受信を開始し、**スマホの音量キー**（またはイヤホンの音量操作）で受信音量が変わるかご確認ください

いつも丁寧なテストとご報告、本当にありがとうございます。
