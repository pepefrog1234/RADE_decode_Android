# v1.5.49 — Bluetooth LE Audio（LC3）イヤホンでの送受信修正

LC3 イヤホンで「受信音声を聴く＋送信もイヤホンのマイクで話す」がうまく動かない問題を修正しました。インストールは `app-debug.apk` をご利用ください。

## 修正内容（4件・いずれも LE Audio 通話モード使用時のみ。他の経路への影響はありません）

1. **送信時にイヤホンのマイクが実際には使われていなかった問題**
   これまでは LE Audio マイクをデバイス ID 指定＋汎用プリセットで開いていましたが、LE Audio のデバイス ID は再構成のたびに変わるため、気づかないうちにスマホ内蔵マイクへフォールバックしていました。本バージョンからは Android の通話音声ルーティング（VOICE_COMMUNICATION）でイヤホンのマイクを確実に捕捉します。

2. **通話モード中の受信キャプチャが LC3 を壊すことがあった問題**
   v1.5.48 で入れた対策（Samsung 端末で UNPROCESSED キャプチャが LC3 グループを壊す件）が、通話モードのセッションには適用されていませんでした。適用範囲を広げました。

3. **受信の入力が誤ってイヤホンのマイクになることがあった問題**
   通話モード中は「既定の入力」がイヤホンのマイクに切り替わるため、入力デバイス未選択の場合、無線機の信号ではなくイヤホンのマイクを復調しようとしていました。未選択時はスマホ内蔵マイクに固定するようにしました。

4. **送信のモデム音がイヤホンに流れてしまう問題**
   USB 出力を選んでいない場合、送信波形が既定ルート＝イヤホンへ再生されていました（耳にピー音が聞こえ、無線機には届かない状態）。スマホのスピーカーに固定するようにしました。

## 使い方

1. v1.5.49 に更新する
2. 設定 →「**送信に Bluetooth マイクを使う（実験的）**」を **ON** にする（これが LE Audio 通話モードのスイッチです）
3. 受信を開始し、イヤホンで復調音声が聴こえることを確認
4. TX に切り替えて話し、相手に「イヤホンのマイクの声」が届いているか確認
5. RX に戻し、イヤホンが無音にならないことを確認（TX⇔RX を数回繰り返してみてください）

## もし問題が続く場合

設定 → 診断 →「**Capture audio log (LC3/BT)**」でログを取得し、コピーして Issue にお送りください。本バージョンのログには `bleCommMic=` / `voiceCommInput=` / `bleAudioOut=` などの新しい項目が出力されるため、どの経路で止まっているかをすぐ特定できます。

## 前提条件

Android 13 以降＋LE Audio 対応のスマホ/イヤホンで、Bluetooth 設定側で LE Audio が有効になっている必要があります（A2DP のままだと通話モードに入れません）。
