# v1.6.14 — PTT 切替と送信音量の改善 / PTT and TX level fixes

v1.6.13 の修正を引き継ぎ、PTT の切替待ちと送信音量の調整を改善しました。インストールには **app-debug.apk** をご利用ください。

## 日本語

- RX→TX 切替時のログ保存待ち（最大 5 秒）を取り除き、保存をバックグラウンドで行います。
- CAT の PTT 応答を厳密に確認し、エラーや遅れて届いた別の応答を成功と誤判定しないようにしました。送信中は受信用 S メーターの問い合わせを省略します。
- 押している間だけ送信する設定で、前回の送信終了待ちに入れた再送信も、ボタンを放すと取り消します。PTT 解除を確認できない場合は画面に表示し、Stop で再試行できます。
- LE Audio 使用中も、USB／スピーカー送信時は音量キーで Android のメディア音量を調整するように修正しました。設定 → TX Output にメディア音量の調整を追加しました。
- AudioTrack が一度に書き込めなかった音声サンプルを続けて書き込み、波形や EOO の欠落を防ぎます。送信音量・実際の出力先・音切れを調べる診断ログも追加しました。

**「ピーク約 5 W」の原因はまだ確定しておらず、実機での出力改善は未確認です。** USB 接続で出力が低い場合は、リグの ALC を確認しながら、メディア音量・TX Level・リグの入力ゲインを少しずつ調整してください。TX Mic Gain は声の大きさの調整です。ネットワーク送信ではリグ／ネットワーク側のドライブ設定をご確認ください。

改善しない場合は、リグの型番、以前のアプリのバージョン、接続方法と、RX→TX（数秒間）→RX を再現した直後の「設定 → 診断 → Capture audio log」をお知らせください。

## English

Builds on v1.6.13. Removes the synchronous reception-log save from RX→TX switching, validates CAT PTT replies against the echoed command and requested state, and skips RX signal-strength polling while transmitting. Releasing hold-to-talk cancels a pending re-key; failed unkey attempts remain visible and can be retried with Stop.

During USB/speaker TX, volume keys now adjust media volume even in an LE Audio session. Settings → TX Output exposes Android media volume separately from TX Level and microphone gain. Partial AudioTrack writes preserve the remaining PCM/EOO samples; TX diagnostics report gain, media volume, routing and underruns.

The reported roughly 5 W peak RF output has **not** been reproduced or verified fixed on radio hardware. Existing gain settings and the EOO/RF tail are retained. The Icom reconnect, analog monitor and RTS PTT features from earlier releases remain included.

## 繁體中文

改善 PTT 切換的存檔等待、CAT 回覆驗證及快速放開發話鍵的處理；修正 LE Audio 下發射時音量鍵調錯音量，新增 Android 媒體音量控制與發射診斷。約 5 W 的實際 RF 功率問題仍待使用者實機驗證，沒有強制提高使用者的發射增益。
