# v1.5.51 — 診断ログ強化版（Bluetooth マイク時に送信にならない件の調査用）

動作の変更はありません。v1.5.50 からの変更は**ログの追加のみ**です。インストールは `app-debug.apk` をご利用ください。

## 背景

v1.5.50 でのご報告（切替遅延は解消・Bluetooth マイクの入力は OK・ただし送信状態にならない）を受けて、原因候補を2つに絞り込みました：

1. 送信エンジンの起動が通話モード中に失敗し、アプリが受信画面のままになる
2. 送信のモデム音声（USB 無線機向け）が、通話モードのルーティングに奪われてイヤホン側へ流れ、無線機に届かない

これまでのログではどちらが起きているか判別できなかったため、本バージョンで以下のログを追加しました：

- 送受信エンジンの起動失敗時の明示的なエラーログ
- 送信音声が**実際に**どのデバイスへルーティングされたかの検証ログ（`TX route@300ms/1500ms: requested/routed/matched`）

## お願い：ログの取得と送付（アプリ内で完結します）

1. v1.5.51 に更新する
2. 現象を再現する：「**送信に Bluetooth マイクを使う**」を **ON** → 受信開始 → TX ボタンを押す（送信にならないところまで）
3. その**直後**に、設定 → 診断 →「**Capture audio log (LC3/BT)**」ボタンを押す（画面にログが表示されます）
4. 「**コピー**」ボタンでコピーし、GitHub の Issue のコメント欄に貼り付けて投稿してください
   - 長すぎて貼れない場合は、メモ帳アプリ等に貼り付けて .txt として保存し、Issue にドラッグ＆ドロップで添付しても大丈夫です
5. あわせて、**スマホの機種名・Android バージョン・イヤホンの型番**もお知らせください

このログが取れれば、次のバージョンで修正できる見込みです。いつもご協力ありがとうございます。
