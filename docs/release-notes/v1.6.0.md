# v1.6.0 — RADE V2 波形に対応（実験的・テスト中）

FreeDV 開発チームが RADE V2 の C 実装をメインラインに統合したことを受け、本アプリでも V2 波形を選択できるようにしました。

## ⚠️ 重要：V2 はまだテスト中です

- **RADE V2 は開発元（radae_nopy）に統合されたばかりで、まだテスト段階の機能です。** 動作・性能は今後変わる可能性があります。
- **V1 と V2 に互換性はありません。** 交信する両局が同じバージョンを選ぶ必要があります（V2 の局の信号は V1 では復調できず、逆も同様です）。
- **通常運用では OFF（V1）のままにしてください。** 設定はデフォルト OFF です。
- V2 では EOO（送信終了）フレームにコールサインのデータが載りません（EOO コールサイン機能は V1 専用。送信終了の検出自体は V2 でも機能します）。

## 使い方

設定 → **RADE モード** → 「RADE V2 波形（実験的）」を ON。受信中に切り替えると自動的に新しい波形で再スタートします。送受信の両方に適用されます。

## 変更内容

- 内蔵 RADE ライブラリを upstream の V2 統合コミット（radae_nopy PR #14）に更新
  - V2 のエンコーダ／デコーダ／同期ネットワーク（新しい NN モデル）を追加
  - upstream の V1 改良も同梱：BPF ミキサーの最適化、SNR 推定の較正定数更新
  - iOS との EOO コールサイン互換に必要な当方のローカル修正（EOO 復調の位相基準とデータシンボル抽出）は維持
- 設定画面に「RADE モード」セクションを追加（4 言語対応）
- APK サイズ：V2 モデル追加により約 +2.5 MB（リリース版 約 24 MB）

## 動作確認のお願い（V2 をお試しになる場合）

1. 両局とも本バージョンにして、両方で V2 を ON
2. まず V1 のまま（OFF）で従来どおり交信できることを確認（回帰確認）
3. V2 に切り替えて同様に交信し、音質・SYNC の安定性・SNR 表示を比較
4. 問題があればログと合わせてお知らせください（接続時に App v1.6.0 がログに出ます）

## English summary

Adds opt-in support for the RADE V2 waveform, following upstream's merge of
the V2 C implementation into radae_nopy mainline (PR #14). **V2 is still
under test upstream**: V1 and V2 are not interoperable on the air (both
stations must select the same version), the setting defaults to OFF, and the
end-of-over callsign remains V1-only (V2's EOO frame carries no data
payload). Toggle lives in Settings → RADE Mode and applies immediately (a
running RX restarts on the new waveform); it affects both TX and RX. The
vendored RADE tree is refreshed to the upstream merge — including upstream's
V1 improvements (BPF mixer optimization, updated SNR calibration constants) —
while preserving this app's local EOO-demod fixes needed for iOS callsign
interop; the build switches from a unity build to per-file compilation
(upstream V1/V2 sources have colliding file-local statics). APK grows about
2.5 MB for the second model set.
