# v1.5.69 — PureSignal：フィードバック飽和と連続再校正を修正

再試験と `log5` の送付をありがとうございました。今回のログではアプリのクラッシュではなく、送信中に PureSignal が約 1 秒ごとに新しい補正を作り続け、補正回数が 0 から 137 まで増加していました。また、Hermes-Lite 2 が実際の ADC オーバーフローを 19 回報告していました。この状態では、クリップしたフィードバックから新しい係数を何度も作り直すため、IMD が改善点を通り越して悪化方向へ動くことがあります。

## 原因

HL2 の TX feedback gain（Protocol 1、アドレス `0x0E`）を extended gain 形式で送るためのビットが不足していました。そのためアプリのログは `-12 dB` と表示していましたが、無線機には legacy code 32、実質約 `+20 dB` として伝わっていました。今回の ADC overflow と一致するプロトコル上の不具合です。

加えて、WDSP を loop delay なしの automatic mode で動かしていたため、最初の補正を保持せず、送信中ずっと係数を交換していました。

## 修正

- HL2 TX feedback gain を正しい extended 形式（`0xC0 | gainCode`、`-12..+48 dB`）で送信
- TX 開始直後は校正を始めず、1 秒間の RX1 feedback／RX2 reference 比で安全な gain を選択
- automatic mode を廃止し、良好な補正を 1 回だけ作る manual one-shot calibration に変更
- ADC overflow を 1 秒区間でラッチし、1 回でも発生した場合は gain を 6 dB 下げる
- overflow が起きた gain より 2 dB 低い上限を保持し、低レベル判定で再び clipping 点へ戻らないように変更
- feedback level の目標を piHPSDR と同じ `140..165` に設定し、通常の校正 gain 調整は最大 4 回または 8 秒で停止（ADC 保護の overflow backoff は停止後も優先）
- gain 変更／overflow 時は処理中の native solver を安全に終了して再作成し、古い clipping candidate が後から係数を交換できないように変更
- PureSignal の MOX delay を 0.2 秒、HL2 TX delay を 150 ns に更新

## 診断ログ

TX health に次の情報を追加しました。

- 実際に無線機へ送っている feedback gain
- その 1 秒間に overflow が一度でもあったか
- solver の試行回数、accepted／rejected 数、最後の判定
- 4 個の fit result と TX/RX sanity-check bitfield
- Android 側の PureSignal controller state と gain ceiling

## 再テストのお願い

前回と同じ出力・周波数で PureSignal ON の送信をお試しください。新しいログでは gain が安全値へ収束した後、`ok` が 1 回増えて controller が `LOCKED` になり、校正回数が毎秒増え続けないことをご確認ください。

この修正はログで確認できた clipping と連続係数交換を除去するものです。実機での IMD 改善量は今回の再試験で確認する必要があり、リリースノートでは改善値を保証していません。

## English summary

Fixes two concrete faults found in the tester's `log5`: the HL2 TX-feedback
gain byte omitted the extended-mode bit, so the displayed `-12 dB` was decoded
by gateware as legacy code 32 (approximately `+20 dB`), and WDSP ran in
zero-delay automatic mode, replacing coefficients continuously. v1.5.69 sends
the correct extended gain code, performs a one-second safe feedback preflight,
runs a bounded manual one-shot calibration, backs off and caps gain after any
ADC overflow, and reports accepted/rejected solver outcomes. Field IMD
improvement remains to be confirmed by the requested hardware retest.
