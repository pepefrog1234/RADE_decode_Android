# v1.6.1 — FreeDV Reporter に RADEV2 を表示

v1.6.0 の補完です。RADE V2 波形を選択している間、qso.freedv.org（FreeDV Reporter）への rx/tx レポートの Mode 欄が **RADEV2** と表示されるようになりました（従来は常に RADEV1）。

- V2 スイッチの切り替えで即座に反映されます（次のレポートから）
- V2 の注意事項は v1.5.0 → v1.6.0 のリリースノートをご覧ください：まだテスト中、V1 と互換性なし、両局同じバージョン必須、デフォルト OFF

## English summary

Companion to v1.6.0: rx/tx reports to FreeDV Reporter (qso.freedv.org) now
carry mode "RADEV2" while the experimental V2 waveform is selected
(previously always "RADEV1"). Takes effect from the next report after
toggling. See v1.6.0 notes for the V2 caveats (still under test, not
interoperable with V1, both stations must match, default OFF).
