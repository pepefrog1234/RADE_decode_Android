# v1.5.54 — Faster TX keying with the Bluetooth mic

Install `app-debug.apk`.

## Bluetooth-mic TX delay (~3 s) reduced

With "Use Bluetooth mic for TX" enabled, keying took about 3 seconds from
pressing TX to the transmission actually starting. Three causes were found and
fixed in `AudioService`:

1. **LE Audio probe removed on phones without LE Audio (~600 ms saved).**
   Every single PTT press first probed for a Bluetooth LE Audio (LC3) headset:
   an audio-mode switch, a 500 ms poll for a device that can never appear on a
   phone without LE Audio support, and a mode switch back. The probe now
   fast-fails instantly when no LE Audio device is connected at all, without
   touching the audio mode. (Phones/headsets that do have LE Audio behave
   exactly as before.)

2. **SCO link now starts negotiating before the RX teardown.** Establishing
   the Bluetooth SCO (call-audio) link costs the BT stack roughly 1–2 s —
   the headset has to suspend A2DP and negotiate eSCO. Previously this only
   started *after* RX was fully torn down and the TX engine built, all serial.
   The route is now requested first, so the link negotiates in parallel with
   the RX teardown and TX setup, and the concrete SCO mic device is resolved
   at the last moment before the TX engine opens.

3. **Silent fallback to the phone mic fixed.** The wait for the SCO mic
   device was capped at 800 ms. When the link took longer (common when the
   headset flips over from A2DP), the app silently transmitted from the
   phone's built-in mic even though the Bluetooth-mic toggle was ON. The wait
   is now up to 2 s with finer 50 ms polling, and if the SCO mic still never
   appears, the half-open call-audio route is cleaned up before falling back.

**What remains:** the eSCO negotiation itself (~1–1.5 s) is inherent to
classic Bluetooth and cannot be removed while RX playback stays on
high-quality A2DP between overs. Expected result: TX keying in roughly half
the previous time. Measured on a Xiaomi 12X without a headset connected, the
whole RX→TX switch completes in ~0.7 s; an on-air test with an SCO headset is
still pending — reports welcome.

## Also included (previously unreleased v1.5.53)

- **TX Mic Gain slider** (Settings → TX MIC, 0.5–15x, default 4x): the TX mic
  fed the encoder unscaled, so other stations heard the modulation too quiet
  and the Digital Gain slider (RX-only) did nothing for it. The TX level
  meter now reads post-gain — what the encoder actually sees.
- **Reliable PTT unkey over Wi-Fi:** a transient rigctld drop right at the
  TX→RX switch could leave the rig keyed. The unkey is no longer gated on the
  momentary connection state and retries with backoff until the rig
  acknowledges.
- Fixed a latent bug where Digital Gain / TX Mic Gain silently reverted to
  defaults after every TX/RX cycle.
