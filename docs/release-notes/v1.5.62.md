# v1.5.62 — 新モード「Thetis (VBAN)」：スマホ⇄Thetis の音声を Wi-Fi 化（PureSignal 対応構成）

ご提案いただいた「オーディオインターフェースの代わりに無線を使う」方式を実装しました。PureSignal は Thetis 側でこれまでどおり動作します。インストールは `app-debug.apk` をご利用ください。

## 仕組み

```
HL-2 ⇄ Thetis（PureSignal ON・無線機は Thetis が管理）
         ⇅ VAC（Voicemeeter の仮想ケーブル、PC 内部）
      Voicemeeter（VBAN・UDP 6980）
         ⇅ Wi-Fi（48 kHz・PCM16・モノラル）
      RADE decode（新モード「Thetis (VBAN)」）
         └ PTT・周波数：内蔵 rigctld → Thetis の CAT サーバー（従来の TCP HL2 プロファイルと同じ）
```

VBAN は VB-Audio 社の公開仕様のネットワーク音声プロトコルで、PC 側は **Voicemeeter（無料）だけ**で受け口になります。追加のソフト開発や仮想オーディオケーブルの別途購入は不要です。

## スマホ側の設定

1. 無線機タブ → 接続モード「**Thetis (VBAN)**」
2. **ホスト** = PC の IP アドレス
3. **VBAN ポート** = 6980（既定のまま）
4. **CAT ポート** = Thetis の CAT over TCP/IP のポート（使わない場合は 0 — VOX 運用）
5. CAT 方言は「Thetis」を選択 → **接続**

## PC 側の設定（一度だけ・構成例）

1. **Voicemeeter**（無印または Banana、[vb-audio.com](https://vb-audio.com/Voicemeeter/) で無料配布）をインストール
2. Voicemeeter 左上の **VBAN** ボタン → VBAN 設定ダイアログ：
   - **Incoming Stream**（スマホ→PC・送信音声）：Stream 名 `RADE-TX`、From = スマホの IP（または Any）、宛先ストリップを選択（例：Strip 1）
   - **Outgoing Stream**（PC→スマホ・受信音声）：Stream 名は任意、IP To = **スマホの IP**、Port 6980、SampleRate **48000 Hz**／PCM 16 bit、Source = Thetis の受信音声が流れているバス（下記）
3. **Thetis** → Setup → Audio → **VAC1** を有効化：
   - VAC Input（Thetis への送信音声）= `Voicemeeter Out`（Strip 1 を B1 などへルーティングした仮想出力）
   - VAC Output（Thetis からの受信音声）= `Voicemeeter Input (VAIO)` → VAIO ストリップを B2 などへルーティングし、それを Outgoing Stream の Source に指定
4. Thetis で PureSignal を有効化（従来どおり）

※ ルーティングは構成例です。要は「スマホからの VBAN 着信 → Thetis の VAC 入力」「Thetis の VAC 出力 → スマホ向け VBAN 送出」の 2 経路が Voicemeeter 内で繋がっていれば OK です。うまくいかない場合は Voicemeeter の画面構成を添えてご相談ください。

## 診断

接続中は 5 秒ごとに `VBAN health: tx=…/s rx=…/s gaps=… stream=…` をログに記録します（設定 → 診断 → Capture audio log で取得可能）。受信ストリームのサンプルレートが 48000 Hz 以外の場合はエラーとして表示します。

## 注意

- 送信音声のストリーム名は **`RADE-TX` 固定**です（Voicemeeter 側の Incoming で選択してください）
- Wi-Fi 省電対策（パフォーマンスロック・DSCP 優先度付け）は HL2 (LAN) モードと同じものを適用済みです
- 遅延は LAN 上で数十 ms 程度で、RADE の交信には影響ありません

## English summary

New connection mode **"Thetis (VBAN)"**: the phone's RX/TX audio rides
Wi-Fi to **Voicemeeter** on the PC using the open **VBAN** protocol
(UDP 6980, 48 kHz PCM16 mono), and Voicemeeter's virtual cables serve as
the SDR host's VAC — replacing the USB sound card + cables between phone
and PC while keeping PC-side features like **PureSignal** fully working.
CAT/PTT optionally bridges through the bundled rigctld to the SDR's CAT
server (same backends as the TCP Hermes-Lite 2 profile: Thetis /
piHPSDR / SparkSDR-Quisk; CAT port 0 = VOX operation).

The app sends its TX audio as VBAN stream **"RADE-TX"** (select it as a
Voicemeeter incoming stream) and accepts any 48 kHz PCM16 mono/stereo
VBAN stream from the configured host for RX (configure a Voicemeeter
outgoing stream to the phone's IP). Wi-Fi performance lock + DSCP EF are
applied as in HL2 (LAN) mode, and a `VBAN health` log line (tx/rx packet
rates, sequence gaps, stream name) supports diagnostics.
