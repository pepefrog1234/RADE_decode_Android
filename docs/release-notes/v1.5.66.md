# v1.5.66 — PureSignal 第 2 段階（後半）：HL2 (LAN) で PureSignal が使用可能に

いよいよです。**HL2 (LAN) モードに PureSignal スイッチ（実験的・既定 OFF）を追加しました。** インストールは `app-debug.apk` をご利用ください。

## 内容

- 無線機タブ・HL2 (LAN) 欄の PA スイッチの下に「**PureSignal（実験的）**」スイッチを追加（既定 OFF）
- ON にすると、送信中に第 2 受信ストリームの PA フィードバックと送信参照信号（時間整合済み）を Thetis と同じ WDSP キャリブレーションエンジンに送り、計算された予歪み補正を送信 I/Q に適用します
- 前回のログ解析より：フィードバックは RX2 に乗っていること、40/20 m で ADC が飽和していたことが判明 → **送信中の LNA を −12 dB に変更**（飽和解消）
- OFF のままなら従来と完全に同一の動作です（1 ビットも変わりません）

## テストのお願い（第 3 段階）

1. v1.5.66 に更新 → HL2 (LAN) 接続 → PA ON のまま **PureSignal を ON**
2. 数十秒送信 → 設定 → 診断 → Capture audio log
3. `TX health` 行の `ps=[cals=… corr=… state=…]` をご確認ください：
   - `state` が 4（収集）→ 6（計算）→ 8（適用継続）と進み、**`corr=1`** になれば補正が効いています
   - `cals` はキャリブレーション完了回数、`dog` が増える場合はフィードバック不調のサインです
4. 可能でしたら、PS ON/OFF での **IMD／スペクトラムの変化**（モニター受信や相手局のレポート）もぜひ

うまく収束しない場合もログさえあれば必ず詰められます。ここまで来られたのは massacho さんの正確なテストのおかげです。

## English summary

**PureSignal is now usable on HL2 (LAN)** — an experimental,
default-OFF switch below the PA toggle. When enabled, the RX2 PA
feedback (time-aligned with the post-correction TX reference via a 4 s
history ring and per-over frozen delay) feeds the vendored WDSP
calibration engine, and the computed predistortion is applied to the TX
I/Q. TX-time LNA is now −12 dB (the 0 dB setting clipped the ADC on
40/20 m per the tester's logs; feedback identified as RX2). With the
switch OFF the TX path is numerically identical to v1.5.64. TX health
gains `ps=[cals dog corr state fblvl]` for convergence diagnostics —
state 4→6→8 with corr=1 means the correction is active.
