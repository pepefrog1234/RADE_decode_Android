# v1.6.6 — RTS PTT（CAT無しインターフェースの自動送受信切替）

FT-897 などを「4端子タイプのデジタルモード用インターフェース」（音声は USB サウンドアダプタ経由、PTT はシリアルの RTS 線、CAT 接続なし）でお使いの場合、これまでは TX ボタンを押してもリグが送信になりませんでした（アプリの自動 PTT は CAT 経由のみだったため）。毎回 Rig タブの RTS スイッチを手動で切り替える必要がありましたが、本バージョンで自動化しました。

## 新機能：RTS PTT

**Rig タブ →「RTS PTT（送信時に RTS で PTT）」** を ON にすると：

- TX ボタンを押す → 自動的に RTS が ON になり、リグが送信状態になります
- RX に戻す → コールサイン（EOO）の送出が終わってから、自動的に RTS が OFF に戻ります（送信が途中で切れることはありません）

※ 使用時は、従来の RTS スイッチ（固定スイッチ）は **OFF のまま**にしてください。

## 使い方のおさらい（FT-897 ＋ DATA端子接続の場合）

1. 無線機：**DIG モード**、メニューで **DIG MODE = USER-U**。キャリアが出ない場合は **DIG GAIN**（DATA 端子の入力レベル）も確認
2. アプリ：**送信出力デバイス＝USB Audio（サウンドアダプタ）**（送信中にスマホ本体からモデム音が聞こえる場合はここが未設定です）
3. Rig タブ：シリアル接続＋「RTS PTT」を ON
4. パワーが低い場合は、設定の **TX Output** スライダーを無線機の PO/ALC メーターを見ながら調整

## In English

New **"RTS PTT"** toggle in the Rig tab: for CAT-less interfaces that key the rig with the serial RTS line, pressing TX now asserts RTS automatically and releases it after the over (after the callsign has played out). Leave the static RTS switch OFF when using this.

No other audio or decoding changes. Install `app-debug.apk`.
