# v1.5.71 — PureSignal：PA モデル診断を追加（AM/AM・AM/PM の実測ログ）

ご質問への回答と、決定的な診断機能の追加です。

## ご質問への回答：オートアッテネーターについて

**はい、内蔵しています。** Thetis の Auto-Attenuate に相当する機能として、アプリは HL2 の TX feedback LNA gain（-12〜+48 dB）を 1 秒ごとに自動調整し、WDSP の feedback level（fblvl、目標 140〜165）に収束させます。前回のログでも自動で `-12 → +3 → +18 dB` と動き、`fblvl=155` で LOCKED しています。つまり「フィードバックのレベル合わせ」は既に自動で、正しく働いています。

## 今回の課題：レベルではなく「中身」の検証

ON/OFF で差が見えない件について、ソフトウェアは 3 送信連続で正常（LOCKED、拒否ゼロ）でした。残る疑問はただ一つです：

**送信中に HL2 の ADC が受けている信号は、本当に PA 出力のサンプルか？**

もしフィードバック経路が PA の非線形性を含んでいなければ（例：T/R スイッチのリーク経由で、実質 PA 手前の信号を拾っている場合）、校正は「ほぼ線形」と判定し、補正はほぼ恒等変換になります。ON/OFF で全く差が出ない現象と正確に一致します。

## v1.5.71 の追加機能

LOCKED のたびに、受理された補正モデルの実測値をログに出力します：

```
PS model: bins 0..15 ym 0.982->1.412 (AM/AM 3.15 dB) AM/PM span 12.4 deg
PS model ym: 0.982,0.991,...
PS model ph: -1.2,0.3,...
```

- **AM/AM**（dB）: 校正が測った PA の圧縮量の逆特性。Drive=255 では PA が約 3〜4 dB 圧縮していることがログ（fwd と drive の関係）から判明しているので、フィードバックが本物の PA 出力なら **AM/AM は +3 dB 前後** を示すはずです。
- **AM/PM span**（度）: 校正が測った位相歪みの幅。

**判定：**
- `AM/AM ≈ 3 dB 以上` → フィードバックは PA を見ています。補正は本物で、問題は別の場所にあります。
- `AM/AM ≈ 0 dB（ほぼ平坦）` → フィードバックに PA の歪みが含まれていません。これはソフトウェアでは修正できない、フィードバック経路（ハードウェア）の問題です。

## お願い：接続構成を教えてください

「サンプラーから HL2 に戻して」とのことですが、現在の構成を教えてください：

1. サンプラー（カプラー）の出力は HL2 の**どの端子**に接続していますか？
   - HL2 のアンテナ端子（送信と同じ端子）の場合、送信中は T/R スイッチで受信部から切り離されるため、フィードバックとして受信されません。
   - PureSignal 用の外部フィードバックには、送信中も受信部につながったままの入力（HL2 の RX 直結入力ジャンパ／IOボード等）が必要です。
2. それとも今回は外部サンプラーなし（HL2 単体、内部リーク依存）でしょうか？
3. 外部アンプは使用していますか？

現在のアプリは「送信中に ADC に届く信号」をそのままフィードバックとして使います（HL2 単体では T/R リーク、外部入力があればその信号）。v1.5.71 のログで AM/AM がほぼ 0 dB なら、リーク経路が PA の歪みを含んでいないことが確定するため、外部フィードバック入力の配線をご相談させてください。

## English summary

Answers the tester's question: yes, the auto-attenuator equivalent is built
in — the app walks the HL2 TX-feedback LNA gain (-12..+48 dB) once per second
until WDSP's fblvl hits 140..165 (logs show -12→+3→+18 dB, locked at 155).
The remaining open question is feedback CONTENT, not level: if the ADC's
TX-time input does not contain the PA's nonlinearity (e.g. T/R-switch leakage
tapping a pre-PA point), calcc fits a near-linear model and the correction is
an identity — exactly matching the observed zero on/off difference. v1.5.71
logs the accepted model at every LOCK (per-bin ym and phase, AM/AM dB and
AM/PM span): with drive=255 known to compress ~3-4 dB, AM/AM ≈ 3 dB proves
the feedback sees the PA; AM/AM ≈ 0 dB proves a feedback-topology problem no
software can fix, and the external-sampler input wiring (an input that stays
connected to the receiver during TX) becomes the fix.
